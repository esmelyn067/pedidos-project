# Gestión de Proveedores y Comerciantes

## Descripción

Plataforma web centralizada que permite administrar proveedores, comerciantes, productos y pedidos desde un único sistema, facilitando la organización de la información comercial y el seguimiento de las operaciones.

## Objetivo

Desarrollar una aplicación web que permita gestionar de manera eficiente las relaciones entre proveedores y comerciantes, optimizando el control de productos, pedidos y transacciones comerciales.

## Criterios de Aceptación

1. El sistema debe permitir registrar usuarios con nombre, apellido, correo electrónico, contraseña y rol (Administrador, Proveedor o Comerciante).

2. El sistema debe validar el correo electrónico y la contraseña para permitir el acceso seguro a la plataforma.

3. El sistema debe permitir registrar proveedores con nombre de la empresa, RNC, dirección, teléfono, correo electrónico y persona de contacto.

4. El sistema debe permitir registrar comerciantes con nombre del negocio, propietario, dirección, teléfono y correo electrónico.

5. El sistema debe permitir registrar productos con nombre, descripción, categoría, precio, cantidad disponible y proveedor asociado.

6. El sistema debe permitir crear pedidos indicando comerciante, proveedor, productos solicitados, cantidad, fecha y estado del pedido.

7. El sistema debe mostrar un historial de transacciones con información de pedidos, fechas, proveedores y comerciantes involucrados.

8. El sistema debe permitir buscar y filtrar usuarios, proveedores, comerciantes, productos y pedidos por nombre, categoría, fecha o estado.
