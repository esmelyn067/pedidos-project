# Gestión de Proveedores y Comerciantes

## Descripción
Plataforma web centralizada que permite administrar proveedores y comerciantes.

## Objetivo
Facilitar la gestión y seguimiento de las relaciones comerciales.

## Tecnologías
- ASP.NET Core MVC
- C#
- SQL Server
- Bootstrap
- Git y GitHub

## Integrantes

## Estado del Proyecto
🚧 En desarrollo

## Requerimientos Funcionales

1. Registro de Usuarios
2. Autenticación de Usuarios
3. Gestión de Proveedores
4. Gestión de Comerciantes
5. Gestión de Productos
6. Gestión de Pedidos
7. Historial de Transacciones
8. Búsqueda y Filtrado de Información
